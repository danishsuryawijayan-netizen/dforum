DOSSIER MALWARE / LAPORAN LAB

KASUS LAB: Prometei, Penyusup Licik yang Bersembunyi di Balik Nama File Sampah

YOGYAKARTA — Beda sama virus abal-abal, malware yang satu ini kelas APT (Advanced Persistent Threat). Namanya Prometei. Dia bukan cuma nongol sebentar, dia modular, licik, dan siap nempel di sistem lo kayak parasit dalam jangka panjang. Tanggal 28 Oktober, kami narik sampel file .elf berukuran 1.2 MB dari MalwareBazaar buat dibedah di lab. Sasaran utama Prometei bukan sekadar nambang kripto, tapi nyuri kredensial (password) lo. Sistem operasi Linux maupun Windows sama-sama jadi incerannya.

Modus Operandi

Buat nangkep dia, kami ekstrak file .zip-nya (password: infected) di PC asli pake 7z x. Abis itu, filenya kami selundupin ke VM REMnux lewat HTTP Server lokal via jaringan Host-Only. Begitu masuk kurungan, PC asli langsung kami bersihin total biar nggak ada sisa. Di dalem lab, kami bedah pake dua cara: Analisis Statis (membedah kode tanpa ngejalanin) dan Analisis Dinamis (ngejalanin virusnya buat liat aksinya secara real-time).

Bongkar Bungkus UPX (Analisis Statis)

Pas awal dicek, file ini ELF 64-bit LSB executable, x86-64, statically linked, stripped. Simpelnya, ini file Linux murni tanpa simbol debug. Tapi, dia pake packer UPX buat nyembunyiin jeroannya. Untung aja kami bisa buka bungkusnya pake perintah upx -d malware2.elf, dan ukurannya melar dari 565 KB jadi 1.3 MB. Pas dibongkar, ini yang nemu:

  • Server Command & Control (C2): Dia nyari IP 177.221.180.26.
  • Jaringan Anonim: Ada alamat .onion (Tor) dan .i2p buat komunikasi cadangan kalau IP utamanya diblokir.
  • Target Pencurian: Dia ngeincer file /etc/shadow, /etc/passwd, dan direktori .ssh/pcc0 (kunci SSH).
  • URL Request: Dia lapor ke server pake pola /cgi-bin/prometei.cgi atau /cgi-bin/p.cgi?auth=hash.

Aksi Licik di Dalam Kandang (Analisis Dinamis)

Pas pertama dijalanin sebagai user biasa (./malware2.elf), dia langsung mati bego! Error-nya Usermode install...Fail. Ternyata dia butuh crontab buat bertahan hidup, dan REMnux nggak punya itu. Kami coba lebih sadis: jalanin pake akses Root (sudo ./crashed.dump). Tunggu, kenapa namanya berubah? Baca bagian selanjutnya.

Plot Twist: Proses Hantu

  • Masquerading (Penyamaran): Pas dijalanin, file asli malware2.elf tiba-tiba menghilang dan ganti jadi file baru bernama crashed.dump (ukurannya sama persis). Dia pura-pura jadi file sampah biar nggak curiga!
  • Systemd Service Palsu: Pas dijalanin sebagai root, dia nampilin pesan sukses: Created symlink /etc/systemd/system/multi-user.target.wants/upluginplay.service. Dia bikin layanan sistem palsu biar otomatis nyala tiap PC reboot.
  • Gagal Total: Meskipun ngaku "OK", sebenarnya upluginplay.service itu broken symlink. Kenapa? Karena koneksi dia ke internet asli dicegat sama INetSim (internet palsu di lab), jadi dia gagal ngunduh file pendukung.
  • Proses Hantu: Pas kami cek pake ps aux, ternyata dia masih jalan di background (sh -c /home/remnux/crashed.dump -Dcomsvc).

Pembersihan TKP (Incident Response)

Karena dia udah kotorin sistem, kami lakuin pembersihan paksa:

  • Kill Process: Matiin paksa pake PID: sudo kill -9 3588 4255 4256
  • Hapus File: Hapus wujud asli dan kloningannya: sudo rm -f crashed.dump
  • Snapshot: Balikin VM ke kondisi bersih kayak sebelum infeksi.

DENGERIN, BEGO! Dokumen ini dibuat cuma buat riset edukasi anonim. Kami nggak nyebarin virusnya. Kalau lo pake info ini buat nyerang orang, itu dosa lo sendiri, jangan bawa-bawa nama DForum.
