Laporan Analisis Malware: Prometei (Linux APT)

Analis: Redaksi DForum | Tanggal: 28 Oktober 2026 | Lingkungan Lab: VirtualBox (Host: Linux Mint) -> VM REMnux (Host-only) + INetSim | Target File: malware2.elf (1.2 MB)

YOGYAKARTA, DFORUM — Sampel yang dianalisis dalam laporan ini merupakan sebuah malware modular tingkat lanjut (Advanced Persistent Threat/APT) yang menargetkan sistem operasi Linux dan Windows. Prometei dikenal karena kemampuannya mencuri kredensial (password), menyebar secara lateral, dan bertahan hidup di dalam sistem (persistence). Sampel yang dianalisis merupakan file eksekusi Linux (ELF) yang dikemas menggunakan packer UPX.

Alur Operasi (Metodologi)

Prosedur analisis dilakukan di lingkungan laboratorium tertutup. Sampel diekstrak pada PC host menggunakan tool 7z x, lalu ditransfer ke mesin virtual (VM) REMnux menggunakan HTTP Server lokal via jaringan Host-Only. PC host segera dibersihkan setelah file dipindahkan. Selanjutnya, penulis melakukan analisis statis (membedah kode tanpa menjalankan file) dan analisis dinamis (menjalankan file untuk melihat aksinya secara real-time), sebelum akhirnya melakukan pembersihan sistem.

Hasil Analisis Statis

Sebelum dijalankan, file diidentifikasi sebagai ELF 64-bit LSB executable, x86-64, statically linked, stripped. File terdeteksi dibungkus menggunakan UPX dan berhasil dibuka menggunakan perintah upx -d; ukurannya membesar dari 565 KB menjadi 1.3 MB. Dari hasil pemindaian strings, ditemukan beberapa temuan kunci:

  • Command & Control (C2) Server: Ditemukan IP 177.221.180.26.
  • Jaringan Anonim: Ditemukan alamat .onion (Tor) dan .i2p untuk komunikasi cadangan jika IP utama diblokir.
  • Target Pencurian: Malware menargetkan file /etc/shadow, /etc/passwd, dan direktori .ssh/pcc0 (kunci SSH).
  • URL Request: Malware menggunakan pola /cgi-bin/prometei.cgi atau /cgi-bin/p.cgi?auth=hash untuk melapor ke server.

Hasil Analisis Dinamis

Saat dieksekusi sebagai pengguna biasa (./malware2.elf), malware gagal berjalan dengan pesan Usermode install...Fail karena membutuhkan crontab yang tidak tersedia di REMnux. Saat dieksekusi sebagai Root (sudo ./crashed.dump), malware berjalan dan mendaftarkan dirinya sebagai layanan systemd. Analisis forensik mengungkap beberapa taktik penyamaran:

  • Masquerading (Penyamaran): File asli malware2.elf menghilang dan diganti dengan file baru bernama crashed.dump dengan ukuran yang sama untuk mengelabui analis.
  • Persistence Palsu: Malware mencoba membuat layanan upluginplay.service. Meskipun menampilkan pesan "OK", file layanan tersebut sebenarnya rusak (broken symlink) karena malware gagal mengunduh file pendukung dari internet yang dicegat oleh INetSim.
  • Proses Latar Belakang: Malware tetap berjalan di latar belakang sebagai sh -c /home/remnux/crashed.dump -Dcomsvc meskipun terminal telah kembali ke prompt.

Tindakan pemulihan dilakukan dengan mematikan paksa proses malware (sudo kill -9 3588 4255 4256), menghapus file asli beserta kloningannya (sudo rm -f crashed.dump), dan mengambil snapshot VM bersih sebagai titik pemulihan.

Indicators of Compromise (IoC)

  • IP Address: 177.221.180.26.
  • File Name: crashed.dump, upluginplay.service, pdefenderd.sh.
  • File Path: /etc/systemd/system/multi-user.target.wants/upluginplay.service.
  • Network: Koneksi ke port 80 (HTTP) dengan parameter URL /cgi-bin/prometei.cgi.

Pelajaran Penting

  1. Adaptasi APT: Prometei menunjukkan bagaimana malware modern dapat beradaptasi dan menyamarkan diri dengan sangat baik.
  2. Pentingnya Internet Palsu (INetSim): Pencegatan koneksi internet asli menggagalkan upaya malware untuk menyelesaikan proses persistence-nya.
  3. Prosedur Insiden: Pembersihan manual setelah sistem terinfeksi malware tingkat lanjut (APT) sangat berisiko, sehingga snapshot rollback adalah pilihan paling aman.

Dokumen ini dibuat sebagai bagian dari riset keamanan siber. Segala bentuk penyalahgunaan di luar konteks edukasi adalah tanggung jawab pengguna.
