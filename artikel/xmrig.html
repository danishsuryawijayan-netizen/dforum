Laporan Analisis Malware: XMRig & Mirai (Cryptominer & Botnet)

Analis: Redaksi DForum | Tanggal: 28 Oktober 2026 | Lingkungan Lab: VirtualBox (Host: Linux Mint) -> VM REMnux (Host-only) + INetSim | Target File: 99e37c7657f4401aa2f3ad96c939e849729daad26daffb7063354821debf0b92.elf (8.6 MB)

YOGYAKARTA, DFORUM — Sampel yang dianalisis dalam laporan ini merupakan sebuah file eksekusi Linux (ELF) berukuran 8.6 MB yang diperoleh dari repositori MalwareBazaar. File tersebut menggabungkan dua jenis ancaman siber sekaligus: XMRig (Cryptominer) dan Mirai (Botnet). Tujuannya adalah mencuri sumber daya komputasi (CPU/RAM) perangkat korban untuk menambang kripto Monero secara ilegal, sekaligus menjadikannya bagian dari "tentara zombie" untuk melancarkan serangan DDoS (Distributed Denial of Service).

Alur Operasi (Metodologi)

Proses analisis dilakukan di lingkungan laboratorium tertutup. Sampel diunduh dengan proteksi password (infected), diekstrak menggunakan tool 7z pada PC host, lalu ditransfer ke mesin virtual (VM) REMnux melalui HTTP Server lokal (python3 -m http.server 8000). Selanjutnya, penulis melakukan analisis statis (membaca isi file tanpa menjalankannya) dan analisis dinamis (menjalankan sampel di lingkungan terisolasi untuk mengamati perilakunya).

Hasil Analisis Statis

Melalui identifikasi awal, file tersebut merupakan ELF 64-bit LSB executable, x86-64 (biner Linux murni). Sampel tidak dikompresi menggunakan UPX (NotPacked), sehingga kode aslinya dapat dibaca langsung. Dari ekstraksi strings, ditemukan beberapa temuan kunci:

  • Situs Mining: Ditemukan string nicehash.com (sebuah mining pool kripto populer).
  • Argumen XMRig: Ditemukan parameter --algo=ALGO dan --keepalive, yang merupakan parameter khas mesin XMRig.
  • Algoritma Monero: Ditemukan algoritma cryptonight-monerov7 dan monerov8 yang spesifik digunakan untuk menambang koin Monero.
  • Konfigurasi Eksternal: Ditemukan referensi ke sysup.org, situs untuk mengunduh file konfigurasi.
  • Sistem Operasi: Ditemukan /bin/sh, indikasi malware dapat mengeksekusi perintah shell.
  • Kriptografi: Ditemukan ratusan OID OpenSSL (AES, SHA, RSA) untuk enkripsi komunikasi.

Hasil Analisis Dinamis

Sampel dieksekusi di dalam VM menggunakan perintah ./malware.elf. Namun, malware gagal berjalan dan langsung berhenti (exit). Pesan kesalahan menunjukkan bahwa file tidak dapat membuka /home/remnux/config.json dan tidak menemukan konfigurasi yang valid. Diagnosis menunjukkan bahwa file tersebut berfungsi sebagai mesin penambang tanpa konfigurasi. Dalam skenario nyata, file ini biasanya dijatuhkan oleh dropper script, misalnya file .sh, yang bertugas membuat config.json. File konfigurasi tersebut berisi alamat dompet (wallet) penyerang dan alamat server mining pool. Tanpa file tersebut, malware tidak mengetahui target penambangan sehingga menghentikan prosesnya sendiri. Pada percobaan ini, pesan error juga merujuk ke https://sysup.org/wizard.

Indicators of Compromise (IoC)

  • Domain/URL: nicehash.com, sysup.org.
  • File Path: /home/remnux/config.json (file yang dicari malware).
  • Hash (SHA-256): 99e37c7657f4401aa2f3ad96c939e849729daad26daffb7063354821debf0b92.

Pelajaran Penting

  1. Fungsi Internet Palsu (INetSim): Penggunaan INetSim sangat krusial. Karena koneksi dicegat, malware gagal mengunduh config.json dari internet asli sehingga mencegahnya beraksi secara nyata.
  2. Efisiensi Analisis Statis: Membaca strings lebih dulu sangat menghemat waktu. Identifikasi XMRig dapat dilakukan sebelum sampel dijalankan.
  3. Kombinasi Payload: Penyerang modern sering menggabungkan beberapa payload (DDoS dan miner) demi keuntungan maksimal.

Dokumen ini dibuat sebagai bagian dari riset keamanan siber. Segala bentuk penyalahgunaan di luar konteks edukasi adalah tanggung jawab pengguna.
