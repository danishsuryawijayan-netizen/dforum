DOSSIER MALWARE / LAPORAN LAB

KASUS LAB: Saat Komputer Lo Diperbudak Jadi Zombie Penambang Kripto Haram

Oleh: Redaksi DForum (Analis Independen) | Tanggal Rilis: 28 Oktober 2026 | Kategori: Investigasi Cryptominer & Botnet

YOGYAKARTA — Dunia siber emang nggak ada habisnya bikin geger. Tanggal 28 Oktober kemarin, tim redaksi lagi asik ngoprek di markas rahasia (baca: Lab VirtualBox). Kami sengaja narik satu sampel file .elf berukuran 8.6 MB dari sarang malware, MalwareBazaar. Bukan file sembarangan, ini file eksekusi Linux murni (ELF 64-bit LSB executable, x86-64) yang dibekali jurus rahasia.

Pas kami bedah, ternyata isinya bukan satu mahluk, tapi dua sekaligus. Di dalemnya ada XMRig (tukang nambang kripto) yang digabung sama Mirai (botnet legendaris). Tujuan mereka cuma satu dan sangat biadab: Nguras sumber daya PC lo tanpa lo sadar!

Kronologi Penangkapan

Kami nggak asal comot file ini ke PC asli, bego! Itu sama aja lo bunuh diri. Prosedurnya rapi. File diunduh dari MalwareBazaar (password: infected), diekstrak pake tool 7z di PC asli, terus dilempar ke dalam kurungan mati namanya VM REMnux. Biar aman, file dikirim lewat HTTP Server lokal (python3 -m http.server 8000) tanpa koneksi internet asli.

Sesampainya di dalem kurungan, kami mulai bedah. Pertama pake Analisis Statis (baca isi file tanpa ngejalaninnya), terus coba Analisis Dinamis (ngejalanin virusnya buat liat dia ngamuk).

Bongkar Jeroan (Analisis Statis)

Pas dipindai pake alat strings (buat ngeliat teks tersembunyi di dalem file), ketahuan deh bokongnya. Untungnya virus ini nggak dikompres pake UPX (NotPacked), jadi gampang diintip.

  • Situs Mining: Ketahuan nyari nicehash.com, situs mining pool kripto populer.
  • Argumen Mesin: Ada parameter --algo=ALGO dan --keepalive, ciri khas mesin XMRig.
  • Target Koin: Dia nyari algoritma cryptonight-monerov7 dan monerov8. Jelas, ini buat nambang koin Monero.
  • Sistem Operasi: Ada string /bin/sh, artinya dia punya akses buat ngeksekusi perintah terminal.
  • Kriptografi: Ratusan OID OpenSSL (AES, SHA, RSA) dipake buat enkripsi komunikasinya biar susah dilacak.

Eksekusi & Plot Twist (Analisis Dinamis)

Nah, ini bagian paling seru. File dijalanin di dalem VM pake perintah ./malware.elf. Kami udah siap-siap liat PC ngebul atau nge-lag. Eh, taunya BAM! File itu malah langsung mati (exit) bego! Dia ngasih pesan error kayak gini: unable to open "/home/remnux/config.json" dan no valid configuration found, try https://sysup.org/wizard

Kenapa Mati? (Diagnosis)

Karena virus ini cuma "mesin" penambang doang, dia nggak punya otak! Dia nggak tau harus nambang buat siapa kalau nggak ada file config.json. Di dunia nyata, para hacker jahat itu nggak asal naruh file .elf gini. Mereka biasanya naro dropper script (kayak file .sh) yang tugasnya nyiapin file config.json (isinya alamat dompet hacker dan alamat server). Tanpa konfigurasi itu, virus ini milih bunuh diri daripada nambang gratisan.

Catatan Redaksi (Pelajaran Penting)

  • Internet Palsu (INetSim) Itu Nyawa: Pas dibedah, kami pake internet palsu (INetSim). Makanya virus ini nggak bisa ngunduh file config.json dari internet asli. Kalau nggak dipalsuin, dia udah ngamuk.
  • Strings Itu Penting: Daripada capek ngejalanin virus, mending cek teks tersembunyi (strings) dulu. Kami udah tau ini XMRig sebelum dia repot-repot jalan.
  • Kombinasi Ganda: Hacker sekarang makin pinter, mereka gabungin DDoS + Miner biar cuannya maksimal. Hati-hati!

DENGERIN, BEGO! Dokumen ini dibuat cuma buat riset edukasi anonim. Kami nggak nyebarin virusnya. Kalau lo pake info ini buat nyerang orang, itu dosa lo sendiri, jangan bawa-bawa nama DForum.
