Laporan Analisis Malware: FritzFrog (Worm P2P Berbasis Golang)

Analis: Redaksi DForum | Tanggal: 28 Oktober 2026 | Lingkungan Lab: VirtualBox (Host: Linux Mint) -> VM REMnux (Host-only) + INetSim | Target File: malware3.elf (16.6 MB -> 22.3 MB setelah unpacking)

YOGYAKARTA, DFORUM — Sampel yang dianalisis dalam laporan ini merupakan sebuah Worm mutakhir yang ditulis menggunakan bahasa pemrograman Golang (Go). Malware ini dirancang untuk menyebar secara mandiri melalui jaringan menggunakan protokol P2P (Peer-to-Peer) dan melakukan serangan Brute-Force pada layanan SSH. Selain berfungsi sebagai penambang kripto (CoinMiner), FritzFrog memiliki kemampuan membuat Backdoor dengan menambahkan pengguna baru pada sistem yang terinfeksi.

Alur Operasi (Metodologi)

Prosedur analisis dilakukan di lingkungan laboratorium tertutup. Sampel diunduh dari MalwareBazaar, diekstrak pada PC host, lalu ditransfer ke mesin virtual (VM) REMnux menggunakan HTTP Server lokal. Penulis melakukan analisis statis menggunakan tools file, upx, dan strings. Sebagai catatan, karena berbasis Golang, hasil ekstraksi strings sangat padat (noisy) dan bercampur dengan memori internal Go. Selanjutnya, sampel dieksekusi dengan hak akses sudo (Root) untuk mengamati perilaku penyebarannya secara dinamis.

Hasil Analisis Statis

Identifikasi awal menunjukkan file tersebut adalah ELF 64-bit LSB executable, statically linked. File menggunakan kompresi UPX dan berhasil di-unpack dari 16.6 MB menjadi 22.3 MB. Dari hasil ekstraksi, ditemukan indikasi protokol jaringan seperti ssh, dns, udp, dan ftp. Temuan kunci lainnya adalah adanya string iaesudonode yang berfungsi sebagai perintah untuk membuat pengguna baru. Penulis juga mendeteksi indikasi kredensial bawaan (default) seperti root, 1234, dan IP 2.5.4.6, yang umumnya menjadi celah keamanan pada perangkat Internet of Things (IoT).

Hasil Analisis Dinamis

Sampel dieksekusi di dalam VM menggunakan perintah sudo ./malware3.elf. Malware tersebut langsung berjalan di latar belakang (background). Beberapa saat setelah eksekusi, terjadi anomali fatal: layar login menampilkan pengguna baru bernama node. Pemeriksaan mengonfirmasi bahwa worm tersebut berhasil menyuntikkan pengguna node ke dalam sistem (/etc/passwd). Taktik ini merupakan bentuk Persistence (pintu belakang) agar penyerang dapat mengakses sistem kembali. Akibat dieksekusi sebagai Root, malware mengubah kredensial sistem dan menyebabkan pengguna asli (remnux) mengalami kegagalan autentikasi.

Indicators of Compromise (IoC)

  • User Account: node (Backdoor yang dibuat malware).
  • Strings: iaesudonode, _E0Fcgodnsudpftpsh.
  • Network: Upaya koneksi keluar melalui SSH (Port 22) untuk menyebar ke mesin lain.

Pelajaran Penting

  1. Waspada Golang: Malware berbasis Go berukuran besar dan sulit dianalisis dengan strings konvensional karena strukturnya.
  2. Bahaya Akses Root: Menjalankan Worm sebagai sudo memberikan kendali penuh untuk mengubah password sistem dan membuat pengguna baru.
  3. Pentingnya Snapshot: Tanpa snapshot, analis harus menginstal ulang REMnux dari awal setelah sistem terinfeksi.

Dokumen ini dibuat sebagai bagian dari riset keamanan siber. Segala bentuk penyalahgunaan di luar konteks edukasi adalah tanggung jawab pengguna.
